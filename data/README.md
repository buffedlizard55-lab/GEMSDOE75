# data/

This folder is intentionally mostly empty in version control (see `.gitignore`):
competition data and large external GIS files must never be committed to this repository
(license terms, repo size, and the fact that the real files are not ours to redistribute).

- `raw/` — place the four organizer files here exactly as named:
  `training_features.tif`, `labels.tif`, `sample_submission.tif`, `1m_DEM_links.csv`.
  See `../scripts/download_competition_data.sh` and `../LIMITATIONS.md`.
- `raw/external/` — place free official external datasets here (see
  `../docs/data/hypotheses.json` for exactly which file each hypothesis needs).
- `processed/` — generated by `../scripts/prepare_data.py`; never edit by hand, always
  reproducible from `raw/`.

Network reachability, tested directly this session

This sandbox's own network (bash/curl) is firewalled to exactly: github.com, codeload.github.com, api.github.com, registry.npmjs.org, pypi.org, files.pythonhosted.org. Every other host above — including www.drivendata.org, gdr.openei.org, docs.nlr.gov, dropbox.com — timed out when curl'd directly.

The separate page-fetch research tool used to read everything on this page runs on different infrastructure and reached most of the hosts above, but could not retrieve binary file content (tested directly against a Dropbox GeoTIFF link — it followed the redirect but returned no usable bytes). See Limitations for what this means for data access.

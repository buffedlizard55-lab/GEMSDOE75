What the competition asks for

The official problem describes fault prediction over GeoDAWN and a single-band float32 GeoTIFF in EPSG:32611 at 100 m, with probabilities/confidence values in [0, 1] and null/NaN outside the submission bounds. Its distance-weighted Tversky metric uses α=0.2, β=0.8, and a 300 m triangular kernel. Read the official problem description before using any result.

Evidence labels matter

A local holdout result is not an organizer score. A projection is not a score. Public leaderboard values are dynamic and are not private-set results. Each experiment must include its holdout evaluator, withheld-positive count, confidence interval, registry comparison, validator result, and raster SHA-256—or clearly say why those checks were not run.

What this project is

GEMSDOE75 targets the DOE GEMS Prize (DrivenData #306): find geological faults in the GeoDAWN survey region of northwestern Nevada that are not already in the USGS/INGENIOUS fault catalogue, submitted as a single-band GeoTIFF of per-pixel fault probability, scored with a distance-weighted Tversky index (DTI, α=0.2, β=0.8, 300 m triangular kernel). Full prize structure: Phase 1 (Initial Round) pays $50,000 across the top 5 on a private pre-registered new-fault set; Phase 2 (Final Round) pays $250,000 across the top 5 after an expert panel expands the label set using every team's submissions. Source: Official Rules PDF, September 2026.

This repository ships three things, each independently tested:

  1. A from-scratch, line-by-line verified implementation of the organizer's own metric (src/gems_doe/metric.py), which reproduces the organizer's published worked example (TPw=3.00, FPw=1.89, FNw=2.00 → DTI=0.60) exactly.
  2. A submission writer/validator (src/gems_doe/submission_io.py) that diagnoses and fixes, by construction, both documented causes of the "Predicted values must be in range [0, 1]" rejection.
  3. A spatially-blocked hide-and-recover holdout evaluator (src/gems_doe/holdout.py) with a built-in leakage canary, ready to run the moment real catalogue data is available.

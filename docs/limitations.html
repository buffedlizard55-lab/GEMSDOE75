Limitations, blockers, and what's needed to unblock them

This page mirrors LIMITATIONS.md in the repository root (read that file for the full text with every verification command). Summary:

  1. No DrivenData login. The data download page requires authentication; verified today it redirects unauthenticated requests to its login page. A human must download training_features.tif, labels.tif, sample_submission.tif, 1m_DEM_links.csv and place them in data/raw/.
  2. This sandbox's network is firewalled to six hosts (github.com, codeload.github.com, api.github.com, registry.npmjs.org, pypi.org, files.pythonhosted.org). Every data host is outside that list, confirmed by direct curl tests.
  3. The research tool that reached more hosts still cannot fetch binary files. Even the free, no-login external datasets our own hypotheses need (shapefiles, GeoTIFFs, zip archives from gdr.openei.org and USGS ScienceBase) cannot be pulled into this checkout automatically — tested directly against a sample link this session.
  4. Consequently, no HOLDOUT-DTI number exists in this repository for any real hypothesis. Every number published here is either (a) reproduced directly from the organizer's own published example, (b) computed from a clearly-labeled synthetic demonstration (dti_mechanics_demo.json), or (c) an ORGANIZER-CONFIRMED live leaderboard figure with a timestamp. Nothing else is reported as a score.

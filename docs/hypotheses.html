Four new, ranked, not-yet-tried hypotheses

Full machine-readable version: data/hypotheses.json. Each one was checked against the fullest sibling-repo hypothesis registry we could read (GEMSDOE32: H33-1 geothermometry, H33-2 catalogue buffer, H33-3 temperature-probe mask, H33-4 paleo-geothermal features, H33-5 tip/step-over extension, H60-1 Monte Cristo Range rupture) to confirm none of the four below duplicate an idea already tried there.

Per this project's own budget rule, none is eligible for a weekly submission slot until it beats the current holdout best on src/gems_doe/holdout.py — which does not yet exist as a number, because the holdout has never been run on real data.

H75-1 — Quaternary volcanic vent/fissure alignment (rank 1)

LayersGDR 1391 Quaternary Volcanics.zip (vents + flows); official RTP magnetics + vertical TMI slope; official magnetic source depth
SignatureDirectional clustering of vent points (Hough/azimuth-statistics) corroborated by a local magnetic-source-depth minimum along the same corridor
Why off-catalogueCataloguers map scarps, not vent/fissure alignments; a dike-induced fracture's surface expression is a cone, not a scarp
Non-fault mimicMagma ascent along non-seismogenic lithospheric heterogeneities (no shear history) — check concordance with the regional strain-rate tensor before trusting
Datagreat_basin_q_volcanics.zip, 9.44 MB, free, CC BY 4.0, DOI 10.15121/1881483 — binary, needs an unrestricted machine to fetch
Cost / valueMedium cost (point-pattern analysis); potentially high value for the Final Round specifically, since this is a genuinely novel structural control

H75-2 — Hypocenter-scatter anisotropy ("seismic streak" detection) (rank 2)

LayersUSGS ANSS ComCat FDSN event API (free JSON, no login); official "density of earthquakes" band used only as a negative control
SignaturePCA eigenvalue ratio + major-axis azimuth of local hypocenter scatter — captures planar alignment that a scalar density band discards
Why off-catalogueA blind/buried fault with no surface scarp can still be seismically anisotropic at depth even while its raw event density looks unremarkable
Non-fault mimicInduced seismicity from geothermal injection/production (e.g. near Steamboat Springs) or legacy mining — check against known well/field locations
Dataearthquake.usgs.gov/fdsnws/event/1/query, free, public JSON API — reachability from our tools not yet tested; first action for next session
Cost / valuePotentially the cheapest to validate of all four (small JSON, not a large binary) if the API is reachable by any available tool

H75-3 — Heat-flow × magnetic-source-depth conjunction (rank 3)

LayersUSGS Heat Flow Maps (DOI 10.5066/P9BZPVUC); official magnetic source depth + surface conductivity bands
SignaturePixels with simultaneously high background conductive heat flow AND shallow magnetic source depth, off-catalogue, linked by a steepest-gradient least-cost path through the strain-rate field
Why off-catalogueTargets blind listric/detachment faults with no surface scarp — a cross-dataset statistical conjunction a scarp-based cataloguer would not use
Non-fault mimicBuried intrusions (no slip-prone fault) or cultural/infrastructure magnetic noise — cross-check against H75-1's vent layer and infrastructure data
Datadoi.org/10.5066/P9BZPVUC (USGS ScienceBase), free — binary, needs an unrestricted machine
Cost / valueHighest implementation cost of the four (two new rasters + a least-cost-path routine); potentially the highest payoff, also the highest confound risk

H75-4 — Slip/dilation-tendency azimuth mismatch vs. catalogue strike (rank 4)

LayersUSGS Quaternary Faulting Slip and Dilation Tendency (DOI 10.5066/P9YL58W6); official strain-rate tensor bands; catalogue fault strike
SignatureCells where the official geomechanical tendency azimuth significantly disagrees (>30°) with the nearest catalogued fault's strike — evidence of unaccommodated strain
Why off-catalogueA disagreement feature by construction excludes anything the catalogue already explains well
Non-fault mimicGravitational/landslide-related extensional fracturing on steep range fronts — exclude via a slope threshold from the official detrended-elevation-slope band
Datadoi.org/10.5066/P9YL58W6 (USGS ScienceBase), free — binary, needs an unrestricted machine
Cost / valueMedium cost; lowest expected payoff of the four — the trigger condition may be rare in a transtensional setting where many faults already track the regional extension direction

Validation plan

  1. Test H75-2's ComCat API reachability first (cheapest, no external machine required if reachable).
  2. Run scripts/download_competition_data.sh on an unrestricted machine; place files in data/raw/ and data/raw/external/.
  3. python scripts/prepare_data.py.
  4. For each hypothesis: implement predict_fn(visible_fault_raster) -> p, run gems_doe.holdout.leakage_canary first (AUC/DTI > 0.90 ⇒ treat as leakage until proven otherwise), then gems_doe.holdout.run_holdout.
  5. Only promote to a real submission slot if pooled HOLDOUT-DTI (with 95% CI) beats the current best.

Executive summary: how to submit a GEMS prediction

The upload steps below are ready to follow; this repository's raster is not.

Current status: NOT READY — no downloadable TIFF.
This checkout has no competition data or validated prediction raster. Do not submit a placeholder or any historical TIFF as this project's result. The DrivenData data page redirects to login in this environment.

Before a file can be offered

  1. Obtain the competition's licensed inputs and the shared template with cached features, holdout evaluator, and submission writer.
  2. Run the preregistered whole-segment, spatially buffered holdout. Build catalogue-based features only from visible faults, mask visible fault pixels exactly, and report pooled distance-weighted Tversky with the official 300 m triangular kernel and α=0.2, β=0.8.
  3. Run feature-by-feature leakage canaries. Investigate any AUC above 0.90 before trusting the signal.
  4. Compare both the continuous candidate surface and final dots against registry artifacts. Stop if rank correlation exceeds 0.90 or if more than 70% of dots are within 3 pixels of a registry raster.
  5. Write the candidate and reopen it independently. Verify one band, float32, EPSG:32611, exact grid shape/transform/bounds, in-footprint finite values in [0,1], permitted outside-footprint null/NaN, and SHA-256.
  6. Only after all gates pass, publish a conspicuous download link with the unique artifact name, <=140-character note, validator receipt, holdout evidence and checksum.

When a validated file is eventually available

  1. Sign in to DrivenData's GEMS competition.
  2. Open its submission form and select the verified single-band .tif file. The official format is a GeoTIFF matching the training data grid: EPSG:32611, 100 m, same bounds/shape/geotransform, one float32 band with values between 0 and 1 and null/NaN outside bounds. Confirm these details against the official problem description and sample submission.
  3. Enter the displayed unique submission name in the platform's name field if available, and paste the displayed short comment into “Note (optional)”. The comment must be at most 140 characters in this project.
  4. Submit and save the organizer's confirmation/receipt. Only that receipt supports an ORGANIZER-CONFIRMED score label. A public leaderboard entry, local holdout, or projection is not that receipt.

What the leaderboard does—and does not—tell us

The official public leaderboard is live and can change. Its displayed score measures public-set performance, not the private test or final award. It does not identify a team's exact TIFF unless the submission record does so. We therefore do not claim that the named H33 TIFF earned the user-reported 0.2778 without a matching organizer receipt.
